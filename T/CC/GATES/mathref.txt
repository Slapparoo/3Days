# One line per kernel expression: the real number it denotes, to 60
# significant digits, and the bit pattern of the double nearest that
# number.  sqrt/ln come from a 60-digit decimal library; asin/acos/atan
# from pi; sin/cos/tan/sinh/cosh of 1 from their Taylor series, which
# converge far past the last double bit for |x| <= 1.  This is NOT a C
# library answer -- a C library is not the oracle for this compiler.  It
# is a ruler: a U line in mathulp.HC prints `kernel quad - reference
# quad`, which inside one binade IS an ulp count, and 0 means the kernel
# answered the correctly-rounded double.  round(2.5) and round(3.5) are
# scored against C's rule (away from zero) because that is the divergence
# being measured; the kernel's own answer is nearest-even.
